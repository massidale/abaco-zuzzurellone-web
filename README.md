# 📖 Abaco Zuzzurellone

Sfida il computer e indovina la parola segreta nascosta nel dizionario italiano.

🚀 **Gioca ora:** [Abaco Zuzzurellone Web](https://abaco-zuzzurellone-web.onrender.com/)

---

## 🎮 Come si gioca

L'obiettivo è indovinare una **parola segreta** scelta dal sistema, restringendo progressivamente il campo di ricerca in ordine alfabetico.

### Le Regole:
1.  **L'inizio**: Il gioco comincia sempre con la parola segreta compresa tra i due estremi del dizionario: **"Abaco"** e **"Zuzzurellone"**.
2.  **Il tentativo**: Inserisci una parola a tua scelta compresa nell'intervallo attuale.
3.  **Il feedback**: Il computer ti dirà se la parola segreta si trova **prima** o **dopo** quella che hai inserito.
4.  **Il nuovo intervallo**: I limiti si stringono in base al tuo tentativo. Il gioco prosegue finché non indovini la parola esatta.

### Esempio di partita:
*Parola segreta: **Salve***

1.  **Range iniziale**: tra *Abaco* e *Zuzzurellone*.
2.  Giocatore: scrive **"Mare"**.
3.  Computer: "La parola è compresa tra **Mare** e **Zuzzurellone**".
4.  Giocatore: scrive **"Topo"**.
5.  Computer: "La parola è compresa tra **Mare** e **Topo**".
6.  ...e così via fino alla vittoria.
